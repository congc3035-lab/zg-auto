## 二、范围与分档原则

分档依据只有一条：**这一步是否需要人的判断**。

- **全自动** —— 结果唯一、无损失风险。脚本必须自动完成。
- **参数化自动** —— 动作固定，阈值与对象由所有者设定，脚本禁止自行改变策略。
- **保留人工** —— 涉及对外发言、消耗付费货币、不可逆操作。脚本禁止触碰。

协议风险已确认排除：该页游不禁止第三方脚本，服务端无验证码与频率限制，
官方亦提供过自动化工具。本文档不讨论封号风险。

## 三、技术前提（已实测）

以下六条于 2026-08-28 在本账号实操验证，不是推测。

| 事实 | 验证方式 |
|---|---|
| 全站动作均为 GET，无 POST 表单 | 领奖、属地开发、出兵、天梯挑战全是超链接 |
| 认证靠 URL 参数 sid，不依赖 cookie | 用无 cookie 的 HTTP 客户端完成了全部操作 |
| 页面为服务端渲染 HTML，不依赖前端 JS | 正则解析即可取到全部动作链接 |
| 无验证码、无频率限制 | 800 毫秒间隔连发 40 余次请求，全程无拦截 |
| 动作链接的 `_r` 是一次性 token | 批量复用同一 token 领 10 项奖励，仅第 1 项生效，其余**静默返回列表页**，不报错 |
| sid 在 URL 中位置敏感 | 手工拼接 sid 被重定向至登录页；必须用页面 href 原文 |

> **核心执行模式**：每执行一个动作前，必须重新拉取列表页取当前 `_r`。
> 禁止一次性抓取多个链接后批量请求 —— 只有第一个生效，且失败无提示。

**数值口径提醒**：本文档中的账号数值（军令、军功、铜币、建筑等级等）
采集于 2026-08-28。所有者期间自行游玩会使其变化，开工前须复核。

## 四、运行架构

### 载体

Tampermonkey 用户脚本，`@match` 绑定 `zg.pccsh.com`。
脚本运行在游戏页面内，直接从 `location.search` 读取 sid，
因此 sid 过期只需重新登录一次，脚本自动接上。代价是必须保留一个浏览器标签。

### 部署端

| 终端 | 角色 | 说明 |
|---|---|---|
| 家中电脑 | 主力 | 承担晚间 18:00–19:00 押镖窗口与常规轮次 |
| 公司电脑 | 受限运行 | **默认启用隐身模式**，见第七节 |
| 手机 | 辅助 | 安卓用 Kiwi / Firefox + Tampermonkey；iOS 用 Safari + Userscripts。**iOS 后台标签会被挂起**，需保持前台 |

### 多端并发约定

三端 localStorage 互相独立，脚本**无法**检测其他终端是否在运行。
两端同时执行会导致编队被并发覆盖 —— A 端切「仅王翦」打战役时，
B 端正用四人阵打天梯，实际变成王翦单挑对方全阵。

1. 每端各有独立的「启用自动执行」开关，**默认关闭**。
2. 同一时刻**只允许一端开启**。切换终端时先关闭前一端。
3. 开关状态存本端 localStorage，刷新后保持。
4. 未开启的终端仍显示浮层与状态，但不发起任何写操作。

### 第一档 · 全自动

| 任务 | 入口 | 执行规则 |
|---|---|---|
| 领周任务奖励 | `/Act/Daily/Index` | 扫全部 `DailyOk` 链接，逐个领完 |
| 领活跃度档位奖励 | `/Act/Daily/Award` | 扫全部 `AwardOk` 链接 |
| 每日签到 | `/Act/Sign/Index` | 每日一次 |
| 血盟祈福 | `/Group/Index/Buff` | 每日一次 |
| 自己属地开发 | `/Build/Operate/Exploit` | 固定「铜钱 + 7 小时」，两块都开 |
| 好友属地开发 | `/Build/Operate/FriendColony` | **仅开发等级 ≥ 40 的好友**，见下方门槛说明 |
| 领天梯排名奖励 | `/Business/Ratk/GetRatkAward` | 每日一次 |
| 武斗场 | `/Act/ArenaPk/Index` | 刷满每日次数 |

属地开发口径：实测「铜钱 + 7 小时」为即时结算，单块进账 379260 铜币，不需等待。

#### 好友属地等级门槛

**规则**：只开发**等级 ≥ 40** 的好友属地。低于 40 级的好友一律跳过，
即使当日次数未用满也**不得**降格去开发低级好友。

**依据**：好友属地开发的收益与该好友的属地等级正相关。实测开发 42 级好友「小歪」
的属地进账铜币 113778；低级好友（如 5 级、26 级）的属地产出显著更低，
消耗一次每日次数换取低收益不划算。

**实现要点**：好友列表页 `/Build/Operate/FriendColony` 在每个好友名后
以 `(NN级)` 形式给出等级，解析该数字即可过滤。列表分页，需翻页收集全部好友。

**边界**：若 ≥40 级的好友属地全部处于休整中，本轮跳过该任务，
**不降低门槛**，等下一轮再试。

### 第三档 · 保留人工

脚本禁止执行，包括不得代为点击确认页：

- 抢镖 —— 由所有者判断时机与目标
- 团队押镖 —— 手动组织
- 世界发言 —— 含小喇叭、大喇叭，属对外发言
- 一切消耗元宝的操作 —— 每日抽奖、商城购买、加速道具
- 装备强化 —— 当前成功率 14%，自动执行会烧光铜币
- 不可逆操作 —— 出售装备、遗忘技能、解散血盟、退出农田占领
- 使用紧急军令补充军令 —— 仓库现存 300 余个，用途由所有者决定

## 六、单轮执行流程

每 20 分钟一轮，对齐军令恢复节奏（每 18 分钟恢复 1 个）。
顺序经过设计，不得随意调整 —— 领取类在前是因为它可能发放紧急军令，
战斗类集中执行是为了避免反复切换编队。

1. **前置校验** —— 读 `/Mine` 取军令与活跃度，确认 sid 有效；读编队，非四人阵则修复
2. **领取类** —— 周任务奖励、活跃度档位奖励、天梯排名奖励
3. **每日一次类** —— 签到、血盟祈福（查当日标记）
4. **属地类** —— 自己两块属地、好友属地（仅 ≥40 级）至上限
5. **战斗类（四人阵）** —— 天梯、擂台免费次数、武斗场、农田争夺
6. **战役（切编队）** —— 算可打次数 `N = 当前军令 − 5`；N ≥ 1 时切「仅王翦」→ 连打 N 次 → 切回
7. **押镖** —— 仅窗口期内执行单人押镖
8. **收尾** —— 再次校验编队为四人阵，写 localStorage，刷新浮层

## 七、隐身模式

为公司电脑场景提供。目标是**屏幕上不出现可辨识的游戏画面**，
脚本照常后台执行，需要时一键唤回。

> **能力边界 · 必读**
>
> 隐身模式只解决**肩窥**问题。它**不能**规避：浏览器历史记录、DNS 查询日志、
> 公司网关与代理的 HTTP 流量审计、终端管理软件的进程与网络监控。
> 对 zg.pccsh.com 的每一次访问在网络层都是可见的，**脚本无法改变这一点**。

### 行为定义

| 项 | 隐身时 | 唤回后 |
|---|---|---|
| 页面内容 | 注入 CSS 隐藏游戏 DOM，页面呈空白 | 恢复原始显示 |
| 标签标题 | 替换为中性文字（可配置） | 保持中性文字，**不还原** |
| 标签图标 | 替换为中性 favicon | 保持中性图标，**不还原** |
| 浮层 | 完全隐藏 | 正常显示 |
| 脚本执行 | **照常执行** | 照常执行 |

标题与图标唤回后不还原是刻意设计：还原会在标签栏产生可见闪变，反而引人注意。

### 唤回方式

- 快捷键切换显示与隐藏，默认 `Ctrl + Shift + G`，可配置
- 快捷键必须避开浏览器与游戏页面已占用的组合
- 隐身状态存 localStorage，刷新后保持
- 公司电脑端**默认开启**隐身，其余终端默认关闭

### 后台标签的定时器节流

Chrome 节流不可见标签的定时器：后台最小间隔 1 秒；
超过 5 分钟不可见后进入 intensive throttling，约每分钟才执行一次。

本脚本 20 分钟一轮，即使精度降到 1 分钟也不影响。但需注意：

1. 浏览器内存紧张时可能丢弃后台标签，脚本随之停止，浮层需显示「上次执行时间」。
2. **不要最小化整个浏览器窗口** —— 最小化的节流比后台标签更激进。
   把游戏标签放后台、其他标签置前即可。

## 八、编队管理规则

编队是全局状态，是本脚本风险最高的部分。

### 两套编队

| 阵型 | 先锋 (a=0) | 前军 (a=1) | 中军 (a=2) | 后卫 (a=3) | 用于 |
|---|---|---|---|---|---|
| 四人阵 | 司马穰苴 | 王翦 | 乐羊 | 伍子胥 | 天梯、擂台、武斗场、农田、押镖 |
| 仅王翦 | 空 | 王翦 | 空 | 空 | 战役 102602 |

### 武将标识

| 武将 | 阵位 | GUID |
|---|---|---|
| 司马穰苴 | a=0 | `723acde6-7f00-4378-a998-2f5baf76ca78` |
| 王翦 | a=1 | `fc4fa2cf-4775-4908-a4e6-12af041df335` |
| 乐羊 | a=2 | `e01a0e22-6fa5-46d0-931f-efb4be56f4e4` |
| 伍子胥 | a=3 | `94efcdbf-65df-421a-a92c-58239c0f8223` |

下阵 `/Build/Operate/Down?a=N`，上阵 `/Build/Operate/UpOk?g=<GUID>&a=N`。
切换一次需 3 个请求，切回需 3 个请求。

### 三重保护

1. **批量执行** —— 一轮内算出可打次数 N，切换一次，连打 N 次，再切回一次。
   禁止每打一次就切换一轮。
2. **异常兜底** —— 战役流程用 `try / finally` 包住，
   无论成功、失败还是抛错，`finally` 中必须切回四人阵。
3. **启动与轮次自愈** —— 脚本启动时、每轮开始前都读一次编队；
   发现处于「仅王翦」立即切回四人阵再继续。

> **为何必须自愈**：若脚本在切成「仅王翦」后被关闭标签、断网或报错中断，
> 编队会永久停在单人状态。下次手动打天梯就是 1 打 4 ——
> 2026-08-28 当天已实际发生过一次，两场天梯挑战因此连败。

## 九、硬约束

### 军令余量

脚本**必须**保留 5 个军令。每次出兵前重新读取当前军令数，
大于 5 才出兵，降到 5 立即停止本轮战役。
脚本**禁止**自动使用紧急军令补充。

### 时间窗口

押镖只在 12:00–13:00 与 18:00–19:00 有效，窗口外返回「未达到押镖时间」。
脚本在窗口外**不得**尝试押镖。

### 请求节流

相邻请求间隔**不得**低于 800 毫秒。该值经实测无拦截，无需更快 ——
一轮日常总计数十个请求，一分钟内可跑完。

## 十、浮层与状态

### 浮层显示内容

- **运行状态** —— 本端开关（默认关闭）、下一轮倒计时、**上次执行时间**
- **关键数值** —— 剩余军令、当前活跃度、铜币、当前编队
- **执行日志** —— 按时间倒序，含时间、任务名、结果
- **控件** —— 启用／停用、立即执行一轮、清空日志、折叠浮层、切换隐身

浮层置于页面右下角，可折叠为小图标，**不得**遮挡游戏原有操作区域。

### sid 失效提醒

检测到请求被重定向至登录页时，脚本**必须**立即停止全部执行，
并在浮层顶部显示红色横幅「登录已失效，请重新登录游戏」。
**禁止**使用 `alert`，它会阻塞页面。
隐身模式下检测到失效时**必须**自动退出隐身以显示该提醒。

### 本地状态

```
zg_auto_state_v1 = {
  date:     "2026-08-31",      // 与今日不符时重置 done
  enabled:  false,             // 本端开关，默认关闭
  stealth:  false,             // 隐身模式，公司电脑端默认 true
  done:     { sign, bless, ratkAward, ... },
  lastRun:  1756368000000,
  log:      [ { t, task, result }, ... ]   // 保留最近 200 条
}
```

换浏览器或清理站点数据会重置状态，后果仅是多发几次无效请求，不会导致错误操作。

## 十一、异常处理

| 情形 | 处理 |
|---|---|
| sid 失效（返回登录页） | 立即停止全部，退出隐身，浮层红条，不得重试 |
| 动作返回列表页（token 失效） | 重取 token 重试 1 次，仍失败则跳过并记录 |
| 网络请求失败 | 重试 2 次，间隔 2 秒；仍失败则跳过该任务 |
| 军令不足 | 跳过战役，继续其余任务 |
| 战斗失败 | 记录后继续，不阻断流程 |
| 战役流程中断 | `finally` 强制切回四人阵；下轮开始前再校验 |
